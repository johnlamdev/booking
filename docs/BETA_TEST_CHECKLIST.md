# 約課易：真實老師與學生試用檢測

這份清單用一位老師、一位學生和兩部手機走完整條流程。請使用測試資料，不要先填真實學生個資。

## 網站管理員先準備

此 repository 尚未提供可直接使用的 Hosted Version。兩部手機測試前，須先按 README 部署網站，取得可由兩部手機開啟的 HTTPS 網址；本機 `localhost` 只能在運行網站的電腦上開啟。

1. 在自己的 Supabase 專案執行 `pnpm db:migrate`，包含 `0016`（改期）與 `0017`（Google Calendar 連接）migration。
2. 確認公開網址、`NEXT_PUBLIC_APP_URL`、Supabase Authentication 允許的 redirect URL 與網站實際網址一致。
3. 為 Supabase Auth 設定自訂 SMTP，並用非 project 成員電郵試註冊；若直接部署在 Vercel，把 `RATE_LIMIT_IP_HEADER` 設為 `x-vercel-forwarded-for`，避免所有學生共用同一個提交限額。本機測試可留空。
4. 如要測 Google Calendar，先填 `.env.example` 中的三項 `GOOGLE_*` 設定；Google OAuth Web application 的 redirect URI 是 `https://你的網站/api/google-calendar/callback`。未設定時，其他約課功能仍可測。
5. 若要執行資料庫整合測試，在有 Docker 的電腦啟動測試 Postgres，設定 `TEST_DATABASE_URL` 指向本機 `booking_test`，再執行 `pnpm test:integration`。此指令會清空該**本機測試資料庫**，不要指向正式 Supabase。

## 老師手機：首次設定

1. 註冊、確認電郵並登入。預約頁應顯示「尚未發佈」。
2. 修改公開名稱、填入可接收 WhatsApp 的老師號碼；檢查示例的 60 分鐘私人課與每週開放時間。
3. 開啟「分享連結」的老師預覽。應可看到課堂和時段，但不能在預覽模式提交查詢。
4. 勾選已檢查資料後發佈，複製公開連結給學生。

## 學生手機：查詢與確認

1. 不登入，開啟老師連結。選課堂和空檔，提交姓名、WhatsApp 號碼。
2. 應看到「等待老師確認」和可保存的狀態連結。按「開啟 WhatsApp，通知老師」，再親自按 WhatsApp 的「傳送」。
3. 老師在「預約查詢」確認課堂，按 WhatsApp 傳送確認訊息。學生重新開啟狀態連結，應看到「老師已確認」。原時段不應再出現在公開空檔。

## 雙方改期

1. 學生在已確認的狀態頁按「想改時間」，選另一個空檔並提出改期。原時段應繼續保留。
2. 老師在已確認課堂的收件匣看見提案，接受後，原筆課堂應顯示新時間；舊時段重新開放。老師按 WhatsApp 通知學生。
3. 另開一筆已確認測試課堂。老師按「提出改期」，選時間並把預填的 WhatsApp 提案連結傳給學生。學生打開連結接受或選「維持原時間」，再用 WhatsApp 回覆老師。
4. 如新時段已被其他已確認課堂佔用，接受改期應被拒絕，不得產生兩堂重疊課。
5. 老師或學生自行提出改期後，試一次「撤回這次改期提案」。原時間應維持不變，然後可重新提出另一個時間；舊的回覆連結不應再能接受。

## 雙方取消

1. 學生在未開始的已確認課堂狀態頁按「取消這堂課」，再次確認後用 WhatsApp 告知老師。舊時段應重新開放。
2. 老師另找一筆未開始的已確認課堂按「取消預約」，再用 WhatsApp 告知學生。學生狀態頁應顯示取消。

## Google Calendar（選測）

1. 老師在「更多 → Google Calendar」連接自己的 Google 帳號並授權。首次連接後按「同步未來課堂」；如頁面提示還有下一批，繼續按直到完成。
2. 確認課堂時，Google Calendar 應出現「約課易 · 課堂名稱」事件，事件內可點約課易後台連結。事件標題不含學生姓名。
3. 雙方完成改期後，**同一個** Google 事件應改成新時間；取消後事件應消失。待確認查詢不應出現在 Google Calendar。
4. Google Calendar 目前只接收約課易已確認課堂；Google 原有活動**不會**反向遮擋約課易空檔。中斷連接後，已建立的舊事件會留在 Google Calendar，須自行刪除。

## 請記錄的問題

記下「哪個角色、哪一步、預期結果、實際結果、畫面截圖（遮去姓名和號碼）」。特別留意學生是否知道要在 WhatsApp 親自按「傳送」，以及老師是否能在 30 秒內找到和處理新查詢。
